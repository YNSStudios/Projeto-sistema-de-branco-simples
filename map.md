# Projeto já iniciado

> Funções implementadas

- Verificação de número
- Verificação de número inteiro
- Cadastro de cliente finalizado
- Salvamento dos clientes no arquivo JSON

> Cadastro do cliente

- Nome completo
- Nome de usuário
- Data de nascimento e idade
- CPF e RG
- Endereço e CEP
- E-mail
- Telefone
- Senha e confirmação de senha

> Login completo

- Entrar usando CPF, telefone ou e-mail
- Procurar o cliente cadastrado
- Conferir a senha
- Avisar quando o cliente não for encontrado
